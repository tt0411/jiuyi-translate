啾译 · 安装说明

要求 macOS 15 或更新版本。

1. 将“啾译.app”拖入 Applications 文件夹。
2. 从“应用程序”启动，然后推出此磁盘镜像。
3. 当前为临时签名、未公证预览版。若系统阻止打开，请确认下载来源，按 Apple 官方指引在“系统设置 → 隐私与安全性”中处理该应用的打开提示：
   https://support.apple.com/zh-cn/102445
4. 菜单栏 → 授权辅助功能；在系统设置中允许当前应用。
5. 在其他应用选中文字，按 Option + D，松开按键并等待翻译。

手动输入翻译无需辅助功能权限。设置中可以自定义翻译快捷键（默认 Option + D）、隐藏菜单栏图标、启用登录时自动启动、查看版本和使用帮助。点击 Dock 图标也可打开翻译窗口。

首次翻译可能需要下载中文和英语语言包：系统设置 → 通用 → 语言与地区 → 翻译语言。
更新版本前请先退出旧进程，再替换应用；临时签名更新后可能需要移除旧辅助功能条目并重新授权。

不要直接在磁盘镜像内长期运行应用，不要关闭系统安全保护。
完整说明请打开此镜像中的“使用帮助.html”，或软件设置中的“使用帮助”。
