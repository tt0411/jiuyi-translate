# 安装与故障排查

## 安装

1. 在本仓库 Releases 下载 DMG（或 ZIP），要求 macOS 15+。
2. 双击 DMG，将“啾译.app”拖到 Applications。
3. 从“应用程序”启动，再推出安装镜像。
4. 当前下载版未公证，首次打开可能被系统阻止。确认来源后参考 [Apple 官方指引](https://support.apple.com/zh-cn/102445)，在“系统设置 → 隐私与安全性”中处理该应用的打开提示。
5. 点击菜单栏翻译图标 → 授权辅助功能；在系统设置中开启“啾译”。手动输入不需要辅助功能权限。
6. 在其他应用选中文字，按 Option + D 并松开。

不要运行要求关闭 Gatekeeper、关闭 SIP、全局移除安全隔离的命令。若提示文件损坏，先重新下载、验证校验和并反馈；不要为了启动而关闭系统安全保护。

## 下载文件校验

把 DMG、ZIP 和同名 `.sha256` 文件放在同一个文件夹。在终端进入该文件夹后运行（版本号按实际下载的替换）：

```bash
shasum -a 256 -c JiuyiTranslate-1.0.0-macOS-universal.sha256
```

只下载 DMG 时也可以运行 `shasum -a 256 文件名.dmg`，与校验文件中 DMG 对应的那一行比较。校验和用于检查文件一致性，不等于开发者签名或 Apple 公证。

## 语言包与翻译失败

在“系统设置 → 通用 → 语言与地区 → 翻译语言”下载中文（简体）和英语。应用只发起这两种语言的翻译请求。混合语言文本可手动选择原文与译文语言，之后点击右上角重试。

自动模式只判断是否含汉字，不是通用语言识别器。日语、韩语及其他语言不属于支持范围；数字、标点和代码变量名也可能没有有意义的翻译。

## 网页取词

⌥D 不负责选择文字：请先用鼠标选中可复制文本。程序首先读取辅助功能选区，失败后等待修饰键松开，再尝试一次 ⌘C。此时不要切换窗口或复制其他内容。某些受保护网页、图片和扫描 PDF 无法读取；可以手动复制后在翻译窗口按 ⌘V。

浏览器、网站和剪贴板管理器可能改变复制行为；不保证所有网页均可取词。剪贴板超过 8 MB 或无法完整备份时会跳过复制兜底。

## 辅助功能已开启但仍提示未授权

临时签名绑定具体构建，更新后可能需要重新授权。

1. 从设置 → 退出应用，关闭旧进程。
2. 在“隐私与安全性 → 辅助功能”移除旧的“啾译”条目。
3. 重新添加“应用程序”中的当前版本并开启权限。
4. 重新启动。在权限提示页可点击“检查权限”或“定位当前应用”。

请固定安装位置，避免同时运行 DMG 内、下载目录内和“应用程序”中的副本。程序不会自行修改你的系统权限。

## 设置、隐藏图标与自启动

菜单栏 → 设置，或者翻译窗口齿轮 → 设置。

- 隐藏菜单栏图标后，⌥D 继续工作。点击 Dock 图标可打开翻译窗口，再从齿轮进入设置。
- “登录时自动启动”在登录当前 Mac 用户后启动程序；若等待批准，点“打开系统登录项”。
- 开启自启动前先固定安装位置。移动或升级后如果自启动异常，在应用内关闭再开启。
- 快捷键默认 ⌥D，可在设置中点“翻译快捷键”按钮后按下新组合键，需包含 ⌘、⌥ 或 ⌃；按 esc 取消，也可恢复默认。仅支持字母、数字和符号键，暂不支持功能键和方向键。
- 若设置中提示组合键被占用，说明已被系统或其他软件注册，请换一个组合键，或使用支持 macOS 服务的应用提供的“服务 → 使用系统翻译”。

## 更新与卸载

更新：退出旧版本，替换“应用程序”中的应用，再重新打开；设置底部显示版本号。没有内置自动更新服务。

卸载：先关闭“登录时自动启动”并退出，再把应用移到废纸篓；系统设置中可移除辅助功能授权。应用只保存界面偏好等设置，不保存翻译历史。尚未下载完的 Apple 语言包或已下载的系统语言包由系统管理，删除应用不会移除它们。
