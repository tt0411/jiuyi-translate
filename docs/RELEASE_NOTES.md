## 啾译 v1.0.0 · 公开预览版

选中文字后按 **⌥D**，使用 Apple 系统翻译完成中英文互译，无需 API Key。

### 下载

- **DMG**：推荐。打开后将应用拖入 Applications，再从“应用程序”启动。
- **ZIP**：解压后手动放入“应用程序”。
- **SHA256**：下载完整性校验。

要求 **macOS 15+**。Universal 包含 Apple silicon 与 Intel 架构；Intel 尚未实机验证。

### 首次使用

1. 安装到“应用程序”，不要直接在 DMG 内长期运行。
2. 菜单栏 → 授权辅助功能，在系统设置允许当前应用。
3. 网页或文档中选中文字，按 ⌥D 后松开按键。
4. 首次翻译可能需要下载中文和英语语言包。也可从设置打开手动输入窗口。

### 本次发布

- 应用图标、离线帮助、手动输入入口与版本显示。
- 卡片浮窗、原文和译文随内容增高且有屏幕高度上限、复制和朗读。
- 浏览器取词失败时尝试复制兜底，并尽可能恢复剪贴板。
- 隐藏菜单栏图标、登录时自动启动和系统服务入口。
- 可复现的 DMG/ZIP 打包脚本与安装、隐私、开发文档。

### 已知限制

此版本使用**临时签名，尚未经过 Apple 公证**。首次打开可能被系统阻止，确认来源后参考 https://support.apple.com/zh-cn/102445 处理打开提示。更新后可能需要重新添加辅助功能授权。

不支持截图 OCR 或中英文以外的语言；不是 Bob 的官方版本。不保证所有网页均可取词。取词过程中避免切换应用或另行复制；第三方剪贴板工具可能记录中间内容。暂无自动更新。
