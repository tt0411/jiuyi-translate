SelectionTranslate · macOS 15+

选中，按 ⌥D，读懂。

只做中英文互译，使用 Apple 系统翻译，无需配置 API Key。

第一次使用

  1. 将应用放入“应用程序”，从该位置启动，再推出 DMG。
  2. 菜单栏 → 授权辅助功能，在系统设置中允许当前的“划词翻译”。
  3. 回到网页或文档，鼠标选中文字，按 ⌥D 并松开按键。
  4. 首次翻译按提示下载英语和中文语言包；也可在“系统设置 → 通用 → 语言与地区 → 翻译语言”下载。

不想授权时，打开设置 → 输入文字翻译，直接输入或 ⌘V 粘贴。

浮窗与设置

上方编辑原文，中间选择中英方向，下方查看译文。含汉字默认译为英语，其余默认译为简体中文。其他语言不在支持范围内。

译文随内容展开，到高度上限后滚动。图钉切换置顶，顶部可拖动，右上角可重试、打开设置或关闭。使用喇叭朗读、复制图标复制。

设置里可以隐藏菜单栏图标和启用登录时自动启动。隐藏图标后 ⌥D 仍可用；再次双击正在运行的应用可打开设置。

取不到网页文字？

先确认文字确实被选中，且当前应用已获辅助功能权限。程序会优先读取辅助功能选区，失败后尝试一次复制取词。按下快捷键后松开，并在等待时避免切换窗口或另行复制。

受限制网页、图片、扫描 PDF、密码框和某些自绘界面仍可能无法取词，可手动复制粘贴。剪贴板超过 8 MB 或无法完整备份时会跳过复制兜底。

已授权但仍提示未授权？

点击“定位当前应用”，确认授权的不是其他目录中的同名副本。临时签名更新后可能需要在辅助功能列表移除旧条目，重新添加当前应用、开启权限，并退出重启。

更新前请退出旧进程，再替换“应用程序”里的应用。设置底部可查看版本。

首次打开被系统阻止

当前公开预览包使用临时签名，尚未经过 Apple 公证。请确认下载来源，并参考 Apple 官方指引处理“隐私与安全性”中的打开提示。不要关闭系统安全保护。

隐私与卸载

本应用不保存翻译历史，不加入广告、遥测或第三方翻译 API。翻译与语言包由 Apple 系统框架处理。

复制兜底会临时读取剪贴板并尝试恢复；切换应用、复制竞争或超时可能影响恢复，剪贴板管理器也可能记录中间内容。应用不会把这些内容写入日志。

卸载前先关闭自动启动并退出，再将应用移入废纸篓；可在系统设置中移除辅助功能授权。

这是应用自带的离线帮助页面，没有分析脚本或外部字体。外部链接仅在点击时打开。
